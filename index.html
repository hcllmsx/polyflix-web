影藏 PolyFlix

把文件藏进一段能正常播放的 MP4 视频里。

生成的文件既是合法的 MP4（双击就能播），又是合法的 ZIP（改后缀为 .zip 就能解压）——这就是“多态文件（polyglot）”。配合影现播放器姊妹项目使用体验更佳。

嵌套结构

MP4 外壳（伪装层，正常播放）
 └─ ZIP 外层（改后缀 .zip 解压，可选 AES-256 密码）
     └─ [可选] 内层 ZIP 或 7z（可选密码）
         └─ 要隐藏的文件

它是怎么工作的？

两步闭环，让“藏”与“现”无缝衔接。

藏

藏

在影藏里挑一段 MP4 当外壳，再选隐藏内容，生成既是合法 MP4、又是合法 ZIP 的多态文件 polyglot.mp4。两种模式：

  • 普通隐写：任意文件打包进 ZIP/7z（可加 AES-256 密码）藏进外壳。
  • 双视频：外壳里再藏一段视频，专供影现播放器“现”出来。
现

现

产物外表就是一段普通 MP4：用任意播放器双击能正常播伪装视频，改后缀为 .zip 又能解压取出隐藏内容，可像普通视频一样通过邮件、网盘、聊天软件等渠道流转。接收方用影现播放器（PC 或安卓）拖入，即自动识别并播放藏在里面的内容，可一键导出。

提示：藏入内容后文件体积会变大，注意别让大小暴露意图。

常见问题

影藏生成的 MP4 经过转码或重新压制后，还能被识别出来吗？

不能。影藏产物依赖原始字节结构来同时伪装成 MP4 与 ZIP，一旦被转码、二次压制、改变封装或重新上传（多数平台会重新编码），隐藏数据就会遭到破坏，影现播放器将无法再识别。请始终保留原始的 polyglot.mp4 文件来播放或导出隐藏内容。

鉴于此，操作前请务必谨慎备份，避免因转码导致隐藏内容永久丢失；由此造成的数据损失，作者恕不负责。

影藏出来的文件真的能正常播放吗？

是的。通过影藏的“双视频”模式构建出的 polyglot.mp4 是合法 MP4，用任何普通播放器双击都能正常播放伪装视频；只有用影现播放器才会“现”出藏在里面的内容。

影现播放器支持哪些格式？

Windows 与 Android 版均基于 media_kit（libmpv / FFmpeg），通吃 MP4、MKV、MOV、FLV、WebM、AVI、TS 等主流格式，并能智能识别影藏双视频。
